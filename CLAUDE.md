# Plug — consignes pour Claude

## Motion design et vidéo

À chaque travail de motion (création, modification ou rendu d'une vidéo) :

1. Charger d'abord le skill `remotion-best-practices` (dans `.claude/skills/`), puis les skills spécialisés qu'il indique (`remotion-markup`, `remotion-captions`, `remotion-render`, etc.).
2. HyperFrames est aussi disponible : le catalogue est dans `engine/motion-library/` (`README.md`, `hyperframes/`, `catalog.json`) et les blocs dans `engine/packages/remotion/hyperframes-studio/`. S'en servir quand un élément du catalogue convient mieux qu'un développement sur mesure.

3. Le skill `animate` (`.claude/skills/animate`, https://github.com/cth9191/animate, MIT) fait des animations procédurales sur `<canvas>`, rendues en MP4, avec des styles (isométrique, math, riso, croquis, encre hachurée, papier découpé, pixel) et une musique synthétisée. C'est un moteur à part, pas du Remotion : l'utiliser quand un de ses styles convient mieux, ou quand l'utilisateur le demande. Ses outils ont besoin de Playwright installé globalement, à la version du moteur : `npm i -g playwright@1.56.1` (le Chromium est déjà dans `/opt/pw-browsers`, ne pas lancer `playwright install`).

4. anime.js (https://github.com/juliangarnier/anime, MIT, v4.5.0) est installé pour `motion/pricing`. Dans Remotion, ne jamais le laisser tourner sur sa propre horloge : passer par `useAnime()` (`motion/pricing/src/motion/anime.ts`), qui crée la timeline en pause et la positionne sur l'image courante (rendu reproductible). Ses easings et `utils` peuvent aussi servir comme fonctions pures. Le `node_modules` du projet est un lien vers `engine/node_modules` : ne pas y lancer `npm install` (risque de supprimer des paquets du moteur) ; pour réinstaller : `npm pack animejs@4.5.0` puis extraire le paquet dans `engine/node_modules/animejs`.

5. Font Awesome Free 7.3.1 (https://github.com/FortAwesome/Font-Awesome) est installé pour `motion/pricing` en paquets SVG (`@fortawesome/free-solid-svg-icons`, `free-regular-svg-icons`, `free-brands-svg-icons`). Les afficher avec `<Icon>` (`motion/pricing/src/components/Icon.tsx`) : du SVG pur, animable, sans fonte web. Licence des icônes : CC BY 4.0, donc créditer « Font Awesome » au générique de toute vidéo qui en utilise ; les icônes de marques restent des marques déposées. Installation à la main comme anime.js (`npm pack` puis extraction dans `engine/node_modules/@fortawesome/`).

6. Google Fonts (https://github.com/google/fonts, licences OFL / Apache) pour `motion/pricing`. Le dépôt complet pèse plusieurs Go : ne pas le cloner. Pour utiliser une famille, la copier localement avec `python3 motion/pricing/scripts/google_font.py "Nom De La Famille"` (fichiers + licence dans `public/fonts/<famille>/`), puis la déclarer avec `registerFont()` (`motion/pricing/src/fonts.ts`) : rendu hors ligne et reproductible. `@remotion/google-fonts` (chargement par nom depuis Google au moment du rendu) est aussi installé, mais ne fonctionne qu'avec un accès internet normal : pas dans le conteneur cloud (le navigateur de rendu n'atteint pas Google à travers le proxy sans désactiver la vérification des certificats, ce qu'il ne faut pas faire).

7. Motion (https://github.com/motiondivision/motion, ex Framer Motion, MIT, v14.0.0 ; paquets `motion`, `framer-motion`, `motion-dom`, `motion-utils`) est installé pour `motion/pricing`. Ses animations suivent l'horloge du navigateur : dans une composition, ne pas utiliser `<motion.div animate>` ni `useAnimate()` tels quels. Passer par `useMotion()` (`motion/pricing/src/motion/motion.ts`, animation mise en pause et positionnée sur l'image) ou par ses fonctions pures (`springValue()` pour un ressort physique, easings `cubicBezier`/`backOut`/`anticipate`, `interpolate`, `mix`). Installation à la main comme anime.js.

8. Le skill `motion-reel-techniques` (`.claude/skills/motion-reel-techniques/`) catalogue les techniques d'un showreel de référence analysé image par image (montage calé sur le tempo, habillage « moniteur », révélation en iris, lettres qui deviennent des points, comparaison d'easings, morphing à ressort, champ de tuiles Truchet, grille 3D, typo cinétique sur les demi-temps). S'en servir pour les accroches, ouvertures de chapitre et révélations. La vidéo de référence n'est pas dans le dépôt et ne doit pas y être : on reprend les techniques, jamais ses éléments.

9. Le skill `word-synced-motion` (`.claude/skills/word-synced-motion/`) catalogue les techniques d'un clip de référence analysé image par image (mots qui apparaissent quand ils sont dits et qui vivent dans l'image : écrits par une étincelle le long d'une courbe, posés sur une surface 3D ou un arc, tapés dans une fenêtre de requête d'IA avec probabilités, tapés dans un formulaire puis tamponnés, allumés par une mèche, posés sur un schéma qui s'anime, compteurs mécaniques). Même palette que l'épisode prix (noir, orange, papier) : à privilégier pour les vidéos avec voix off, à partir des temps des mots (`voice/transcript.json`). La vidéo de référence n'est pas dans le dépôt et ne doit pas y être.

Les skills Remotion viennent de https://github.com/remotion-dev/skills (version 4.0.534). Pour les mettre à jour, recopier le dossier `skills/` de ce dépôt dans `.claude/skills/`.
